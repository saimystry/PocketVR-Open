# Contributing to PocketVR

Thanks for helping. The most useful thing right now is testing on hardware we don't have.

## Report what you tried

Please open an issue with your graphics card, phone, headset, connection type and game, whether it worked or not. NVIDIA, Intel and other phones are especially useful.

For a bug, open **Help** in the PC app, click **Save a support file**, and attach it.

## Send code

1. Read [spec.md](spec.md) and [AGENTS.md](AGENTS.md).
2. Build and run the tests, as described in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
3. Keep changes focused, and add tests for behaviour changes.
4. Only report hardware results that really happened.

## Rules

- **Clean room:** don't copy from or decompile proprietary VR software.
- **Licences:** shipped dependencies must be permissive, with no GPL, AGPL or LGPL.
- **Secrets:** never commit keys, credentials or build output.

Contributions are accepted under the Apache-2.0 licence.
